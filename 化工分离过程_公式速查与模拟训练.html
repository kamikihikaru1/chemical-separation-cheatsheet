★ Rachford-Rice 方程（闪蒸）Ch.2 · 最高频大题
核心
标准形式
f(ψ) = Σ zᵢ(Kᵢ-1) / [1 + ψ(Kᵢ-1)] = 0
求组成
xᵢ = zᵢ / [1 + ψ(Kᵢ-1)] yᵢ = Kᵢ · xᵢ
推导来源
物料衡算(Fzᵢ=Vyᵢ+Lxᵢ) + 相平衡(yᵢ=Kᵢxᵢ) + ψ=V/F联立消去xᵢ,yᵢ
单调性
f(ψ)对ψ严格单调递减，两相区内只有唯一根
根区间
0 < ψ < 1（两相区）；避开分母极点 ψ=-1/(Kᵢ-1)
迭代方法
Newton法：ψ_new=ψ_old-f(ψ)/f'(ψ)；初值ψ₀=0.5
绝热闪蒸
外层迭代T，内层用R-R求ψ；热量衡算 Q=VHᵥ+LHₗ-FHF=0 校验T

★ Fenske 方程（全回流最少板数）Ch.3 · 精馏第一步
核心
标准形式
N_min = ln[(x_D,LK/x_D,HK)·(x_B,HK/x_B,LK)] / ln(ᾱ_LK,HK)
平均相对挥发度
ᾱ = √(α_顶 × α_釜) [几何平均]
非关键组分全回流分配
dᵢ/bᵢ = (d_LK/b_LK) · αᵢ,LK^N_min
推导本质
每级：(yLK/yHK)=α·(xLK/xHK)，N级连乘后取对数
使用条件
全回流(R=∞)；恒摩流；平均α代表全塔
为什么ln？
多级过程是指数积累，对数取出指数就是级数
α越大
分母越大 → N_min越小 → 越容易分离
分离要求越高
分子越大（产品更纯）→ N_min越大
ᾱ计算易错
必须是几何平均√(α顶×α釜)，不是算术平均！
★ Underwood 方程（最小回流比）Ch.3 · 精馏第二步
核心
第一方程（求θ）
Σ αᵢzᵢF / (αᵢ - θ) = 1 - q
第二方程（求Rmin）
Σ αᵢxᵢD / (αᵢ - θ) = Rmin + 1
θ的约束
α_HK < θ < α_LK (必须满足！)
θ的物理意义
夹点参数，代表最小回流时塔内夹点处的"虚拟挥发度"
q值的影响
泡点液(q=1)→右端=0；饱和汽(q=0)→右端=1；过热汽q<0
迭代求θ
二分法，区间(α_HK, α_LK)；f(θ)=Σαᵢzᵢ/(αᵢ-θ)-(1-q)=0
xᵢD的近似
理论上用最小回流下的塔顶组成；实际中用Fenske全回流结果代入（可接受误差）
为什么存在夹点
最小回流→推动力→0→某级需无限多平衡级→夹点出现
多组分注意
若有n个关键组分区间，就有n个θ根；通常只取αHK<θ<αLK那个根
★ Gilliland 关联（实际理论板数）Ch.3 · 精馏第三步
高频
无因次变量定义
X = (R - Rmin) / (R + 1) Y = (N - Nmin) / (N + 1)
Molokanov近似公式
Y = 1 - exp[(1+54.4X)/(11+117.2X) · (X-1)/X^0.5] 简化: Y ≈ 0.75(1 - X^0.5668)
反解N
N = (Y·Nmin + Nmin - Y) / (1 - Y) → 向上取整
物理意义
X→0（R刚超Rmin）→Y大→N多；X→1（R→∞）→Y小→N→Nmin
工程本质
能耗（回流比）和设备投资（塔板数）的折中关系
使用步骤
①算X→②查图或公式得Y→③反解N→④向上取整
典型工程R值
R=(1.2~1.5)Rmin为工程最优区间（N和操作费折中最优）
★ Kremser 方程（吸收/气提）Ch.4 · 吸收大题
高频
理论级数公式（吸收，A≠1）
N = ln{ [(y_{N+1}-mx₀)/(y₁-mx₀)]·(1-1/A) + 1/A } / ln(A)
吸收因子
A = L / (m·V) [液/气 × 1/m]
气提因子
S = m·V / L = 1/A [气/液 × m]
推导本质
每级物料衡算+相平衡形成递推等比数列，对N级求和取对数
适用条件
平衡线和操作线均为直线（稀溶液）；A在全塔恒定
A的物理意义
A>1→液多→利于吸收；A<1→液少→吸收不完全
多组分吸收
各组分独立计算Aᵢ；用关键组分的Aᵢ求N；用N反算其他组分出口
气提用法
将A替换为S=1/A，y₁和y_{N+1}对换（稀端在顶）
与Fenske的类比
两个方程结构相似：都是多级递推的对数表达，本质相同
双膜传质系数Ch.4 · 双膜理论
重要
以气相为基准
1/Ky = 1/ky + m/kx
以液相为基准
1/Kx = 1/(m·ky) + 1/kx
传质速率
N_A = Ky·(y - y*) = Kx·(x* - x)
为什么液膜阻力要乘m
液相阻力1/kx折算到气相推动力基准时，需通过平衡关系y=mx换算，所以乘m
气膜控制条件
m小（气体易溶如NH₃）→m/kx项小→1/Ky≈1/ky→气膜控制
液膜控制条件
m大（气体难溶如O₂）→m/kx项大→1/Ky≈m/kx→液膜控制
化学吸收强化
反应消耗溶质→界面xᵢ↓→推动力↑→速率增加→E=化学/物理速率>1
Langmuir 吸附方程Ch.7 · 吸附等温线
重要
标准形式
q = q_m · b · P / (1 + b·P)
线性化（用于实验求q_m和b）
P/q = 1/(q_m·b) + P/q_m → 作P/q vs P图，斜率=1/q_m，截距=1/(q_m·b)
两个极限
低压: q ≈ q_m·b·P (线性) 高压: q ≈ q_m (饱和平台)
4个假设
①单层吸附 ②表面均匀 ③吸附位等效 ④分子间无作用
为什么有平台
表面吸附位有限，全部占满后q不再增加
vs Freundlich
Freundlich适合非均匀表面，无饱和上限，经验方程
对应等温线类型
L型（Langmuir型）等温线，最常见
